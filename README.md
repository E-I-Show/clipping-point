# CLIPPING POINT

> 要約：Pyxelで作る、初代PS時代風ローポリゴンのレースゲーム。設計と開発計画が済み、実装は段0（立ち上げ）から始める。文書は `docs/`、設計時の試作は `spikes/` にある。

Pyxel 3.0の3D機能（Pyxel Cube）を使い、市販車スタイルのスポーツカーでクローズドサーキットを周回するレースゲームです。走行後のリプレイは保存でき、シアターで後から読み込んで再生できます。配布物はブラウザで動く単一のHTMLファイルです。

## いまの状態

設計と開発計画まで済んでいます。ゲーム本体のコードはまだありません。次は、土台と検証の仕組みを置く段0（立ち上げ）です。

## どこに何があるか

| 場所 | 中身 |
| --- | --- |
| `docs/canon/planning.md` | 企画書。正本 |
| `docs/design/overview.md` | 実装設計。全体の設計 |
| `docs/plan.md` | 開発計画。段の並び、区切り、通過条件 |
| `docs/img/` | 文書の図と試作の画面 |
| `docs/review/` | 設計に対する批評と、直しの確かめの記録 |
| `spikes/` | 設計のために作った試作と実測の記録。出荷物には含めない |

## 進め方

設計、実装、検証、作業記録はClaude Codeが行い、game-dev-pilotの手順に沿って1段ずつ進めます。段ごとに「設計、批評、確かめ、区切りの実装」の順で積み、各段の終わりに実機での確認をお願いします。詳しくは `docs/plan.md` にあります。
