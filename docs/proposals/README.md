# 改訂案

> 要約：正本（`docs/canon/planning.md`）と実装のずれ、方向を決める材料、急がない案をためる所。正本への反映は人が決める。Claudeは、採られた改訂案だけを、番号を添えた単独のコミットで正本に当てる。

## 決まり

- 正本は、採られた改訂案を当てるコミット以外では書き換えない。
- ずれに気づいたら、その区切りの中で改訂案を1件起こす。実装は設計のとおりに進め、正本は触らない。
- 1件は1ファイル。名前は `NNNN-<短い英語の名>.md`。番号は起こした順。
- 頭に要約と、札、状態、伺う時を書く。案には推奨を添える。
- 状態が変わったら、下の一覧と、そのファイルの頭を直す。採用のときは、正本に当てたコミットを書く。

## 札と状態

| 札 | 意味 |
| --- | --- |
| 方向 | 遊び方、表示の方式、正本の変更。人に伺って決める |
| 細目 | 任されている範囲。推奨で決めて事後報告にする |
| 釣り合い | 数値の合わせ。仮の値で進め、段4で合わせる |

状態は「未決」「採用」「見送り」の3つです。
