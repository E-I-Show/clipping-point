## やること

### 1. 車両モデル（`clipping_point/cp_core/vehicle.py`）

- 車の値の型（定義データの項目から作る。書き換えられない）と、車（状態を持つ）。状態は、設計の表のとおり：位置、向き、世界座標での速度、ヨーレート、実舵角、ならした車体加速度、ギア、回転数、変速の残り時間。過給は、持たない（ターボを入れないので）。
- 1 tickを進める口：舵角の指令（rad。左が正）、アクセル（0〜1）、ブレーキ（0〜1）、路面の摩擦係数を受ける。中の順と式は、試作のまま（細目の3番の所を除く）。
- 変速の口（上げる、下げる、後退へ入る、前進へ戻る）。ATは、試作の決め（上げる回転数、下げる条件、変速中は駆動力0）。
- 外から、位置と世界座標の速度を置き直す口（壁の押し戻し用）。車体座標の速度も、一緒に置き直す（試作は、tickの終わりに置いた車体座標の速度を、次のtickの駆動系が読むので、外から速度だけを書くと、1 tick古い値が使われる）。
- 出す量（輪ごとの前後と横の使用率、車体の滑り角、ヨーレートの目標との差）は、試作のまま計算する。使うのは、段1の操作補正とアシスト。
- 式の中に、数字の直書きを残さない（細目の4番）。物理の定数（重力加速度、単位の換算）は、名前を付けた定数でよい。

### 2. コース（`clipping_point/cp_core/track.py`）

- コースの定義データの項目から、表を作る。表は、作った後は書き換えない。
- 照会：位置（x, z）と、前回の区間の番号（無ければ、全部を探す）を受けて、コースに沿った距離、横のずれ（左が正）、向き、曲率、路面の種類、左右の舗装の端と壁の位置、壁までの距離、区間の番号、取り直したか（前回の区間の近くで探し当てられず、全部を探したか。前回の区間が無い呼び出しは、取り直しに数えない）、を返す。高さは、いつも0。前回の区間の番号は、呼ぶ側（世界）が持つ。
- コースに沿った距離と横のずれから、位置と向きを引く口。
- 壁の押し戻し：車を、向きつきの長方形として、壁へのめり込みを求め、押し戻して、減速させる（試作の式と値。値は、コースの定義データか、車の値に出す）。
- 形の検査（細目の19番）は、定義データの読み込み検査から呼べる形にする（問題の文を返す）。

### 3. 操作補正の最小版（`clipping_point/cp_core/controls.py`）

- 状態：舵角の指令（前のtickの値）、ブレーキを押し続けているtick数。後退中かは、持たない（細目の9番）。
- 1 tickの口：入力フレームと、車の、いまの値（車速、ギア、最大舵角、ホイールベース、タイヤが最大グリップを出す滑り角、路面の摩擦係数）を受けて、舵角の指令、アクセル、ブレーキ、変速の指示（後退へ、前進へ、無し）を返す。
- 車速に応じた最大舵角は、設計の式（`上限 = min(車の最大舵角, ka × L × a ÷ v² + km × αp)`。車速が1 m/s未満なら、車の最大舵角）。切る速さは、上限に対する割合で決める（設計の「ステアリングの補正」）。
- 後退（細目の9番）。後退中の、舵の向きと、ペダルの読み替えを、テストで固める。

### 4. 世界（`clipping_point/cp_core/sim.py`）

- `Sim` の作り方を変える（細目の11番）。呼んでいる所（`cp_app/app.py`、`tools/input_reference.py`、`tools/fingerprint.py`、テスト）を直す。アプリは、車の id とコースの id を、定数で持つ（`# 割り切り：` の注。選択画面は段1）。
- テストと道具が、世界を作るための口（定義データを読んで、世界を作る。車を、決めた位置と速度に置く）を、`cp_core` に置く。出荷するコードの、ふつうの道では、使わない。
- 進行距離：コースに沿った距離の差を、積み上げる（巻き戻さない。後ろへ動いた分は、引かない）。1 tickで、ありえない量（40 m）を超えて変わったら、足さない。
- 走行の数え（細目の14番）：最高速、変速の回数、壁に当たった回数（当たり始めを1回と数える。押し付けられている間は、増やさない）、後退に入った回数、照会を取り直した回数。
- 要約（細目の11番、12番、14番と、「要約の項目」の表）。項目を足したら、`tests/test_sim.py` に足す。
- 操作補正の状態（舵角の指令、ブレーキを押し続けているtick数）は、世界が持つ。
- 世界の状態から、仮の表示の値を作る所は、pyxel を読まない関数に出す（置き場は、層の向きに合うほう）。走る台本と壁の台本の全tickで、表示用の値を作れること（後退のギア、芝、壁に当たっている間も）を、テストする。

### 6. 指紋と筋書き

- 台本を2つ足す：`tools/input_script_drive.json`（走る台本。900 tick）と、`tools/input_script_wall.json`（壁に当たって、止まり、後退して、向きを変えて、前進へ戻る）。台本は、入力だけ（運転役は、段1）。作る補助を使ってよい（細目の22番）。
- `tools/fingerprint.py` の筋書きに、2本を足す（末尾に）。筋書きは、車の id、コースの id、走行の下限を持つ。下限は、要約の値だけで判定する：走る台本は、進行距離、最高速、変速の回数、最後に舗装の上にいること、壁に当たっていないこと。壁の台本は、壁に当たった回数、後退に入った回数、最後に前進に戻っていること、最後の進行距離。走る台本は、照会を取り直した回数が0であることも、下限に入れる。下限を満たさなければ、道具 fingerprint は1（写しと同じでも）。`--update` は、下限を満たさない筋書きが1本でもあれば、何も書かずに1（細目の14番）。下限の値は、筋書きの定義に置く。車とコースの id は、道具の1か所から引く（細目の21番）。
- いまの筋書き2本（120 tick）も、車が入るので、要約が変わる。下限は、持たなくてよい。
- 指紋の写しは、最後に、作業ツリーの上で取り直す（細目の15番）。報告に、取り直した回数と、最後の取り直しの後に回した検証を書く。保存する項目の一覧の写し（`tests/snapshots/profile_schema.json`）は、変わらないはず（変わったら、報告する）。

```python
cmd = controls.step(params, state, frame, car.speed, car.gear, spec.max_steer, spec.wheelbase, spec.peak_slip, spec.tire_mu, mu)
if cmd.shift == controls.SHIFT_TO_REVERSE:
    entered = car.shift_to_reverse()  # True のときだけ、後退に入った
elif cmd.shift == controls.SHIFT_TO_FORWARD:
    car.shift_to_forward()
car.step(cmd.steer, cmd.throttle, cmd.brake, mu)
q = track.query(car.x, car.z, hint)  # q.requeried を数える。hint = q.index
x, z, wvx, wvz, hit, impact = track.push_out(q, car.x, car.z, car.wvx, car.wvz, car.heading, spec.half_length, spec.half_width)
if hit:
    car.relocate(x, z, wvx, wvz)
mu = track.surface_mu(q.surface)  # 次のtickへ
```

### 後半で気を付ける所（前半の報告から）

- 照会は、別の道の区間を `hint` に渡すと、その道の上の答えを返す（取り直さない）。車を、離れた所へ置き直した後（テストと道具の、置き直す口）は、`hint` を None にする。
- `push_out` の後の `q.s` と `q.lateral` は、押し戻す前の位置の値。要約に入れる値は、押し戻した後の位置で、どう取るかを決める（取り直しに数えない形で）。
- 変速の回数は、`step` の前後の `car.gear` を比べれば数えられる。後退の出入りも変わるので、後退に入った回数は、`shift_to_reverse()` の戻り値で数える。
- 変速は、13 tickかかる（0.2秒＝12 tickではない。試作のまま）。
- 高いギアのまま壁で止まると、ATが1速へ下げ終わるまで、後退へ入れない（5速からは約0.9秒。指示は毎tick出る）。
- 無い id は `KeyError`。起動時に、分かる文にする。
- 規則ファイル `data.md`（7,976バイト）と `controls.md`（7,949バイト）は、上限8,000の間際。足すなら、ほかへ書くか、短くしてから。
- 表 `assists` は、アナログ操作用とデジタル操作用の2組を、1つの項目（id は `default`）の中に持つ。
- わざと壊す検査（selftest-break）は、前半の後に、主が、並列に回す形へ直した（343件で約17分半。全体の検証は、`--selftest` つきで約19分）。時間に頼る件（コマンドに `web_smoke.py`、`verify.py`、`--realtime` がある件）は、1件ずつ回る。足した道具（走る台本の回など）が、時間に頼るなら、`tools/selftest_break.py` の `is_timed()` と、`tests/test_selftest_tool.py` に足す。件の名は、重ならないこと（重なると、2で止まる）。
- 「回す検証」の節の「約25分」は、約19分に読み替える。
