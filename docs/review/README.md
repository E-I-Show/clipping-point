# 批評と確かめの記録

> 要約：実装設計と開発計画に対する観点別の批評（レビュー役の指摘を反証役が確かめ直したもの）と、直しの後の確かめの結果。設計の決まりの理由を引くときに使う。

| ファイル | 中身 |
| --- | --- |
| `round1.json` | 批評。鍵 `review:<観点>` に指摘、`refute:<観点>` に反証の結果 |
| `confirm1.json` | 確かめ。指摘ごとの解消の判定、直しで生まれた食い違い、3タブと図の校閲 |
| `confirm2_assist.json` | 操作補正の観点の確かめ。ほかの6観点より後に回した |
| `<観点>.txt` | 批評を読みやすく並べたもの |

## 批評の集計

| 観点 | 指摘 | 反証を通った |
| --- | --- | --- |
| 詰み | 15 | 12 |
| 企画書との整合と足し忘れ | 15 | 13 |
| 決定性・リプレイ・保存 | 15 | 12 |
| ブラウザ版と配布 | 12 | 10 |
| 検証できるか・見かけの合格 | 15 | 13 |
| game-dev-pilotとの整合 | 15 | 9 |
| 操作補正と車両の挙動 | 14 | 12 |
| 合計 | 101 | 81 |

## 確かめの集計

- 指摘ごとの判定: 一部 13件、解消 56件
- 直しで生まれた食い違い: 21件（重複を含む）
- 校閲で見つかった食い違い: 25件

操作補正の観点の批評は、ほかの6観点の確かめより後に終わったので、確かめを別に回した（`confirm2_assist.json`）。

- 指摘ごとの判定: 解消 9件、一部 3件（対象は反証を通った12件）
- 直しで生まれた食い違い: 15件
- 確かめられなかったこと: 6件（図の描いた結果、批評役だけが回した数字の再現、試作に実装の無い規則など）

一部の3件と食い違いの15件は、実装設計と開発計画に反映してある。反映の後の確かめは回していない。

記録の中の「タブ」は、設計時のドキュメントのタブを指す。リポジトリでは、企画書が `docs/canon/planning.md`、実装設計が `docs/design/overview.md`、開発計画が `docs/plan.md` に当たる。記録が引く版（rev）は設計時のドキュメントのもので、リポジトリの写しは最後の直しまでを含む。
