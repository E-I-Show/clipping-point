# 車両モデル（cp_core/vehicle.py と、車の定義データ）

## 約束

- 車輪の回転を状態に持たない4輪モデル。`Car.step(舵角の指令, アクセル, ブレーキ, 路面の摩擦係数)` の1回が1 tick。刻みの長さは受けない。
- 1 tickの中を `SUBSTEPS`（2）回に分け、世界座標の速度を積分する。各輪の横力と制動力は、その輪を分割1回で止める力まで（止める力の頭打ち）。外すと、極低速で静止しない。
- 舵の速さは制限しない。舵角の指令を、車の最大舵角で切るだけ（切る速さは、操作補正の1か所で決める）。
- エンジンブレーキは、駆動輪の制動の要求に足す（車輪の進む向きに逆らう）。負の駆動力にしない（前進ギアのまま後ろ向きに動くと、加速する）。
- アクセルとブレーキは0〜1。範囲の外、NaN、負の摩擦係数は `ValueError`（黙って丸めない）。
- 角度は rad、左が正（舵角、ヨーレート、車体座標の横の速度）。座標と単位は、根の `CLAUDE.md` の「土台の方針」。
- 車の値と式の値（タイヤの式、LSD、ATの変速点、変速時間、エンジンブレーキ）は、全部、定義データの車の項目に置く。`vehicle.py` に置く数は、物理の定数、単位の換算、`SUBSTEPS`、0で割らないための守りだけ。
- 車の項目は、入れ子（`body`、`steering`、`engine`、`drivetrain`、`lsd`、`tires`、`suspension`、`brakes`、`aero`、`rest`、`outputs`）。鍵の名の終わりに単位を付ける（`_kg`、`_m`、`_rad`、`_s`、`_rpm`、`_ps`、`_n`、`_m_s`、`_m2`）。
- 0で割ることになる値（質量、重量配分、ホイールベース、タイヤの半径など）は、表の定義の範囲で0を外す。
- 車の値（`CarSpec`）は書き換えられない。項目から作るのは `spec_from_entry()`。車（`Car`）は、車の値を受けて作る。
- 位置と速度を外から置くときは `Car.relocate()`（車体座標の速度も置き直す）か `Car.reset()`。属性を直に書かない（次のtickの駆動系が、1 tick古い速度を読む）。
- 車の値の矛盾の検査（`spec_problems`）は、`vehicle.py` に置き、`datadefs.py` が読み込む。`vehicle.py` からは `datadefs` を読み込まない。
- ターボ、セッティングの対応、荒れた路面、輪ごとの路面、後輪ブレーキの倍率、MTの操作は、段1の「車両モデル」の区切り。

## 値を読む口

- 車の値の型と、鍵の意味：`CarSpec` の注。表の定義は `cp_core/datadefs.py` の `CAR_FIELDS`
- 状態（位置、向き、世界座標の速度、ヨーレート、実舵角、ならした車体加速度、ギア、回転数、変速の残り時間）：`Car` の属性。まとめて比べるのは `Car.state()`
- 変速の口：`shift_up()`、`shift_down()`、`shift_to_reverse()`（1速で、変速中でなければ受ける）、`shift_to_forward()`。受けたら True
- 出す量（段1の操作補正とアシストが使う）：`wheel_util`（前後の使用率）、`wheel_sy`（横の使用率）、`body_slip`、`yaw_err`。輪の並びは `WHEELS`
- 後退のギアの番号：`REVERSE`（−1）。重力加速度：`GRAVITY`
- 設計の表の値からの幅（テストが使う）：`tools/budgets.json` の `vehicle_` で始まる値

## Xを足したらYも

- 車の項目に鍵を足したら、`CAR_FIELDS`、`CarSpec`、`spec_from_entry()`、実物の `cars.json`（`_notes` に「仮の値：」）、`testpacks/extreme/cars.json` の2台に足す。壊した場合は、`tests/test_datadefs.py` が鍵の道から作る。
- 式を変えたら、`tests/test_vehicle.py` の参照値（`MIXED`）を置き直し、指紋の写しを取り直す（単独のコミット）。`STRAIGHT` は、試作の値。変わるのは、舵0・全開の直進に効く式を変えたときだけ。
- 車の値を変えたら、設計の表の値（0-100 km/h、最高速、制動距離、最大横加速度）のテストを見る。データの版は、段0の間は1のまま。
- 矛盾の検査を足したら、`tests/test_vehicle.py`、`tests/test_datadefs.py` の `BROKEN`、`tools/selftest_break.py` に足す。

## テストと道具

- テスト `tests/test_vehicle.py`：設計の表の値の近く（試作の測り方）。参照値。止まること（惰性でヨーレートが反転し続けない、ブレーキで行き過ぎない）。アクセルを離している間、運動エネルギーが増えない。舵を制限しない。AT。後退。範囲の外の入力。
- 道具 selftest-break の `test_vehicle_` で始まる件：止める力の頭打ち、分割数、エンジンブレーキの形、舵の速さの制限を、テストが拾うこと。
- 道具 `python3 tools/check.py --only data`：車の値の矛盾（`check_data_car_` で始まる壊す件）。

## 落とし穴

- 変速の残り時間は、小数で減らす。0.2秒の変速は、12 tickでなく、13 tickかかる（試作と同じ）。
- 舵0・全開でも、発進の空転とLSDで、わずかに横へ動く（zと向きが、0ちょうどにならない）。
- 後退中に左へ切ると、車体の向きは右へ回る（前輪は左を向く）。舵の符号を、後退で反転しない。
- 前進のギアで、回転数がアイドリングより低い速さ（1速で毎秒約1.9 m未満）では、クラッチが滑っている扱いで、エンジンブレーキが掛からない。
- 浮動小数の結果は、デスクトップ版とブラウザ版で一致しない前提。試作と同じ値になるのは、同じ環境の中だけ。
