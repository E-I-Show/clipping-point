# コース（cp_core/track.py と、コースの定義データ）

## 約束

- コースの表（`Track`）は、定義データのコースの項目から `build_track()` で作る。作った後は、書き換えない（値はタプル。属性を書くと `AttributeError`）。同じ中身の項目からは、同じ表が返る。
- 作り方：制御点（x、z）→ 周期的な3次スプライン（曲率が連続）→ 細かい点列 → 約2 m刻みの等間隔の表。簡易なスプライン（Catmull-Rom）にしない（最小半径が、最大42%小さくなる。試作の実測）。
- 表の点ごとの値：位置、接線、向き（巻き戻さない）、曲率、幅の半分（＝舗装の端）、左右の壁の位置。壁は、必ず最外周に置く。
- 座標は、平面 (x, z)。向きは +x が0、+z が +π/2。横のずれは、左が正。曲率は、左へ曲がるとき正。
- 照会（`Track.query(x, z, hint)`）は、前回の区間（hint）の近くだけを探す。届かなければ、全部を探して取り直し、`requeried` を True にする。hint が無い呼び出し（スタート、置き直した後）は、全部を探す（取り直しに数えない）。
- 前回の区間の番号は、呼ぶ側（世界）が持つ。車を、離れた所へ置き直した後は、hint を渡さない（別の道の区間を渡すと、その道の上の答えが返る）。
- コースに沿った距離は、0以上、全長未満。高さは、いつも0（平地だけ）。路面の種類は、舗装と芝だけ。
- 壁の押し戻し（`Track.push_out()`）は、位置と世界座標の速度を返すだけ。車へ置くのは、呼ぶ側（`Car.relocate()`）。向きとヨーレートは、変えない。
- 形の検査（`shape_problems`）は、`track.py` に置き、`datadefs.py` が読み込む。`track.py` からは `datadefs` を読み込まない。
- 形の検査は、先に、退化した形（点が足りない、制御点の間隔が0.5 m未満、閉じていない、短すぎる、長すぎる）を見て、表を作る計算に進まない。次に、表を作って、1周で閉じること、最小半径、内側の折り返し、スタートが舗装の上にあることを見る。
- 制御点は、頭の点を、末尾に繰り返さない。仮の周回路の制御点は、式から作る（`python3 tools/claude/make_test_loop.py`）。手で書き換えない。
- 高さ、勾配、バンク、縁石、グラベル、区間ごとの幅と路肩、グリッド、通過点、理想ライン、自己交差の検査、描画用のメッシュは、段1と、段0 区切り10。

## 値を読む口

- 照会の結果の項目（`s`、`lateral`、`heading`、`curvature`、`surface`、`half_left`、`wall_left`、`to_wall_left`、`index`、`requeried` など）：`TrackQuery` の注
- 位置を引く口（照会の逆）：`Track.pose_at(s, lateral)`。スタート位置：`Track.start_pose()`
- 路面の種類の名：`SURFACES`。摩擦係数：`Track.surface_mu(路面の種類)`（コースの項目の `surface_mu`）
- 壁へのめり込み：`Track.wall_contact()`。壁の反発と摩擦は、コースの項目の `wall`。車体の半長と半幅は、車の値
- 表の全長、点の数、刻み、1周の向きの変化：`Track.length`、`n`、`ds`、`turning`。点1つは `Track.sample(番号)`
- 照会が歩く点の数の上限：`QUERY_MAX_WALK`。形の検査の線：`MIN_RADIUS_M`、`FOLD_MARGIN`、`MIN_GAP_M` など（`track.py` の頭）
- コースの項目の鍵：`cp_core/datadefs.py` の `TRACK_FIELDS`

## Xを足したらYも

- コースの項目に鍵を足したら、`TRACK_FIELDS`、`Track`、実物のファイル（`_notes` に「仮の値：」）、`testpacks/extreme/tracks/wide_test_loop.json` に足す。壊した場合は、`tests/test_datadefs.py` が鍵の道から作る。
- 仮の周回路の寸法を変えたら、`make_test_loop.py` の定数を変え、出た行を、実物と試験用データの両方へ写し、`--check` を回す。`_notes` の寸法と、`tests/test_track.py` の頭の寸法も直す。指紋の写しを取り直す（単独のコミット）。
- 路面の種類を足したら、`SURFACES`、照会の `surface`、コースの項目の `surface_mu`、世界が摩擦係数を引く所に足す。
- 形の検査を足したら、`tests/test_track.py`、`tests/test_datadefs.py` の `BROKEN`、`tools/selftest_break.py` に足す。

## テストと道具

- テスト `tests/test_track.py`：仮の周回路の表（全長、点の数、1周で閉じる、直線の曲率、半円の半径）。照会と、位置を引く口が、互いに逆。前回の区間つきと、無しで、同じ答え。正しい前回の区間なら、取り直さない。遠い区間なら、取り直して、同じ答え。壁の押し戻し。形の検査。
- 道具 selftest-break の `test_track_` で始まる件（照会が前回の区間を使わない、取り直さない、壁の押し戻しを外す）と、`check_data_track_` で始まる件（閉じていない、最小半径、制御点が全部同じ点）。
- 作業の補助 `python3 tools/claude/make_test_loop.py [--check]`：制御点を式から作る、定義データと照らす。

## 落とし穴

- 表を作る計算は重い（デスクトップ版で約4ミリ秒、ブラウザ版で約15〜25ミリ秒）。`build_track()` は、同じ中身の項目の表を覚えていて（直近の `BUILT_MAX` 個）、形の検査と世界で、同じ表を使う。`Track(項目)` を直に呼ぶと、毎回作る。
- 壁へのめり込みは、車の中心の区間の法線で測る（壁の曲がりを見ない。半径15 mで、最大約0.15 mの差）。
- 照会が歩いて届くのは、前へ15区間、後ろへ16区間まで（約30 m）。1 tickに、それより動かす置き直しは、取り直しになる。
- 半円の内側へ、曲率の中心を越えて出た点は、照会が1つに決まらない。壁の内では起きない（内側の折り返しの検査で、そういうコースを弾く）。
- 鍵ごとの規則を通っても、形によっては、表を作る計算が止まる（0で割る）。読み込み検査が、その項目の問題の行に直す。
